# Dr. Cholan's Ortho & Derma Care Clinic — website revamp

A redesigned, mobile-friendly website for Dr. Cholan's Ortho & Derma Care Clinic, Pammal, Chennai.

- **`site/`**: the website itself, a static page with no build step. Open `site/index.html`, or serve it with `python -m http.server --directory site`.
- **`site/data.js`**: opening hours, reviews and "What's bothering you?" answers. Edit these here and the page updates itself.
- **`assets/original/`**: every image from the current website, listed in `manifest.md`.
- **`assets/generated/`**: new lifestyle images generated for the redesign.
- **`content/site-content.md`**: all text from the current website, organised by page.

Booking opens WhatsApp with a ready-made message to 93604 01654, so no server is needed.
